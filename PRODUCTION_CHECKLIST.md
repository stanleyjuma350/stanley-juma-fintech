# Production checklist

- [ ] Register the operating company and confirm applicable Kenyan financial-service licensing/partnership requirements.
- [ ] Implement secure backend API (HTTPS only).
- [ ] Implement phone OTP and session/token management.
- [ ] Implement KYC/identity verification.
- [ ] Implement M-PESA STK Push, C2B/B2C as applicable, callbacks and reconciliation.
- [ ] Create double-entry transaction/loan ledger.
- [ ] Implement credit scoring and configurable loan rules.
- [ ] Implement approval workflow and staff roles.
- [ ] Implement automated repayment schedules and arrears/PAR logic.
- [ ] Implement SMS/push/email notifications.
- [ ] Implement admin dashboard and audit trail.
- [ ] Add rate limiting, fraud controls, encryption, backups and monitoring.
- [ ] Perform penetration/security testing.
- [ ] Complete privacy, consumer-protection and regulatory review before launch.
